Instructions

  1. Select Outer Board or Inner Board.
  2. Tap the map to manually add a point.
  3. Or press 📍 Add My Location to use your phone's current GPS location.
  4. You can press Add My Location multiple times to create multiple GPS points.
  5. Drag any pin to adjust its position.
  6. You need at least 3 points to create a polygon.
  7. Press Finish Polygon when you are finished. This automatically saves the polygon to geofence.csv on the computer running the server — no download or file transfer needed.
  8. Use Clear Outer or Clear Inner to remove a boundary. (This clears it on the map only; press Finish Polygon again with a new set of points to overwrite what's saved.)
